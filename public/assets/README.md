# 收款码图片放这里

会员支付的收款码图片放在本目录。支持「**每个套餐一张固定金额码**」，扫码即付固定金额，无需对方手动输入。

## 推荐：固定金额收款码（按套餐）

为每个套餐各生成一张固定金额码，命名如下（Welcome 页选套餐时自动切换对应的码）：

| 套餐 | 金额 | 微信文件名 | 支付宝文件名 |
| --- | --- | --- | --- |
| 1 个月 | ¥50 | `pay-wechat-50.png` | `pay-alipay-50.png` |
| 3 个月 | ¥150 | `pay-wechat-150.png` | `pay-alipay-150.png` |
| 12 个月 | ¥600 | `pay-wechat-600.png` | `pay-alipay-600.png` |

> 文件名里的数字 = `public/welcome.html` 顶部 `PLANS` 里配的路径，改价时一并改文件名即可。

### 怎么生成固定金额码
- **支付宝**：首页「收钱」→「**设置金额**」→ 输入金额（如 50）→ 保存/截图二维码。
- **微信**：「收付款」→「**二维码收款**」→「设置金额」→ 输入金额 → 保存二维码。

## 备用：通用码（对方手动输金额）

没做固定金额码时，放这两张通用码即可，所有套餐都用它（页面会回退到这里）：

| 用途 | 文件名 |
| --- | --- |
| 微信通用收款码 | `pay-wechat.png` |
| 支付宝通用收款码 | `pay-alipay.png` |

## 说明

- 优先用「套餐固定金额码」；找不到对应文件时自动回退到通用码；通用码也没有时，页面显示「收款码尚未配置」。
- 只放微信或只放支付宝都行，另一个会自动隐藏。
- 价格 / 套餐月数 / 收款码路径都在 `public/welcome.html` 顶部的 `PLANS` 数组里改。
- 当前为「**人工收款 + 一键开通**」：用户付款后点「我已付款」→ 管理员邮箱收到带「一键开通」链接的通知 →
  核对到账后点链接选时长即开通（也可在 `/admin → 会员管理` 手动开通）。
- 固定金额码只是让对方少付错钱，**不会**自动回调服务器，仍需你核对到账后开通。
