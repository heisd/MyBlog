# 收款码图片放这里

会员支付用的收款码图片放在本目录，文件名必须如下（Welcome 页会自动读取）：

| 文件名 | 用途 |
| --- | --- |
| `pay-wechat.png` | 微信收款码 |
| `pay-alipay.png` | 支付宝收款码 |

## 怎么做

1. 打开微信/支付宝 →「收款」→ 保存你的收款二维码图片。
   - 建议用「**收款码**（可备注/可改金额）」而不是固定金额码，方便不同套餐付款。
2. 把图片重命名为上面的文件名（`.png`，也可用 `.jpg` 但要同步改 `welcome.html` 里的 `src`）。
3. 放进这个 `public/assets/` 目录，提交并部署（Vercel）。

## 说明

- 只放了其中一个也没问题，另一个会自动隐藏。
- 两个都没放时，Welcome 页会显示「收款码尚未配置，请联系管理员」。
- 价格 / 套餐月数在 `public/welcome.html` 顶部的 `PLANS` 数组里改。
- 当前为「**人工收款 + 后台手动开通**」：用户付款后点「我已付款」会给管理员邮箱（`CONTACT_TO`）发通知，管理员在 `/admin →
  会员管理」为该邮箱「+N 个月」即可。
